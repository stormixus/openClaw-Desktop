# Hwatu Card Assets

48 Korean hwatu (화투) card images used by the Matgo and Go-Stop games.

## Format

- Format: `PNG` (300px wide, rendered from SVG)
- Filename pattern: `<month>-<kind>-<index>.png`
- `month`: `1` to `12`
- `kind`: `bright`, `animal`, `ribbon`, `pi`
- `index`: position in the engine's `MONTH_KINDS` array (1-based)

When a file is missing, the UI falls back to the built-in CSS card rendering.
